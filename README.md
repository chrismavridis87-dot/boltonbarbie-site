

## Constant Neon Edition

This version adds:

- Cursor-following neon aura on desktop
- Animated top scroll-progress light
- Moving left and right neon rails
- Continuously drifting pink, blue and purple auroras
- Falling cyberpunk laser beams
- Pulsing navigation and live button
- Breathing hero logo with automatic light sweeps
- Animated neon section dividers
- Constant card, schedule, rewards, social and FAQ glows
- Moving Bolt On Barbie brand ticker
- Mobile performance reductions
- Full `prefers-reduced-motion` accessibility support

### Run this edition

```powershell
cd "C:\Users\Admin\OneDrive\Documents\Boltonbarbie\bolt-on-barbie-constant-neon"
npm install
npm run dev
```

Open the address printed in the terminal, normally:

```text
http://localhost:3000
```
