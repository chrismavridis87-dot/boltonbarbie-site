BOLT ON BARBIE — DEPLOYMENT-READY IRL WEBSITE

This is the IRL-only public deployment version.

INCLUDED
- Render Blueprint configuration
- Automatic IRL live/offline detection
- Secure server-side Kick credentials
- Health-check endpoint
- Node version configuration
- Custom-domain-ready deployment
- Social links, schedule and offline screen

SECURITY
Never upload or commit a .env file.
Never paste KICK_CLIENT_SECRET into GitHub.
Add both Kick credentials only when Render securely prompts for them.

GITHUB UPLOAD
1. Create a new PRIVATE GitHub repository named:
   boltonbarbie-site
2. Do not add a README, .gitignore or licence during repository creation.
3. Extract this ZIP.
4. In the empty repository, choose:
   Add file > Upload files
5. Upload the CONTENTS of the bolt-on-barbie-deploy-ready folder.
6. Commit the upload to the main branch.

RENDER DEPLOYMENT
1. In Render, choose New > Blueprint.
2. Connect the boltonbarbie-site GitHub repository.
3. Render reads render.yaml automatically.
4. When prompted, securely enter:
   KICK_CLIENT_ID
   KICK_CLIENT_SECRET
5. Create/apply the Blueprint.
6. Wait for the deploy to finish.

CUSTOM DOMAIN
After the Render site works on its onrender.com address:
1. Open the Render service.
2. Go to Settings > Custom Domains.
3. Add:
   boltonbarbie.com
4. Follow Render's displayed DNS instructions in Cloudflare.
5. Return to Render and click Verify.
